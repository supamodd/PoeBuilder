## Снаряжение

- [ ] Без билда страница показывает предупреждение, кнопки недоступны. С билдом — слоты и пустое хранилище.
- [ ] Нажатие на слот доспеха открывает редактор; в списке только Body Armour. Выбор базы показывает свойства и implicit.
- [ ] Поиск базы/мода/вставки фильтрует списки. Добавление мода подставляет максимальные значения; значения вне диапазона отклоняются при сохранении.
- [ ] Второй мод той же группы, второй префикс у magic, мод не из пула — отклоняются с понятным текстом.
- [ ] Указать 1 гнездо → добавить руну/идола с эффектом для доспеха → сохранить → предмет надет в слот. Вставка с семейным лимитом недоступна в списке.
- [ ] Лук в «Осн. рука I» + колчан во «Втор. рука I» — надевается. Колчан без лука, щит к двуручному мечу — отклоняются.
- [ ] Переключение «Набор I / Набор II» меняет видимую пару слотов; надетое во втором наборе не пропадает.
- [ ] Undo/redo, дублирование, снятие, удаление, очистка (с подтверждением) работают. Ctrl+S + перезапуск восстанавливают всё.
- [ ] Флакон HP и оберег создаются и надеваются в свои слоты.

## Восхождения

- [ ] Создать/открыть билд → Witch → Blood Mage. Список восхождений соответствует классу, открывается мини-дерево.
- [ ] «Основное дерево» возвращает основной граф; «Мини-дерево восхождения» — выбранный мини-граф. Поиск и инспектор относятся к текущему графу.
- [ ] «Всё дерево» вписывает именно текущий граф, а не все исходные восхождения. Колесо, drag и фокус работают.
- [ ] Обычный путь выделяется, снимается, undo/redo работают. На Sanguimancy цена 0; число выделенных узлов не выдаётся за потраченные очки.
- [ ] Основной лимит и лимит восхождения независимы. Изменение одного не меняет другой. 8 — начальный ручной лимит восхождения, не сведения об испытаниях персонажа.
- [ ] Смена восхождения требует подтверждения, не меняет основной граф. Отмена диалога возвращает предыдущий ComboBox-выбор; undo восстанавливает восхождение и выделения.
- [ ] Смена класса с восхождением требует подтверждения и сбрасывает оба графа. Undo возвращает прежний класс/восхождение/выделения. Нет самопроизвольных диалогов при открытии сохранённого билда.
- [ ] Выбор «Без восхождения» возвращает основной граф; undo возвращает восхождение.
- [ ] Abyssal Lich имеет свой фон и описания, без смешивания с обычным Lich.
- [ ] Узлы выбора варианта/условные/выдающие дополнительные очки явно заблокированы, не выглядят поддержанными.

## Сохранения и регрессии

- [ ] Ctrl+S, перезапуск, открытие: оба дерева, выбранное восхождение, атрибуты и два лимита восстановлены.
- [ ] Старый schema 3 (0.3) открывается без потери дерева и восхождения; до Save файл не изменён, после Save есть прежняя `.bak`, снаряжение/умения пустые.
- [ ] Экспорт/импорт и копия переносят дерево, снаряжение и умения с новым ID билда.
- [ ] Смена билда очищает общую историю, не переносит восхождение другого билда. Несохранённые изменения защищены запросом.
- [ ] Язык UI меняется без перезапуска. EN игровые строки пока остаются EN, предупреждение об этом видно; это известное незакрытое требование.
- [ ] Undo заметок не меняет дерево; Ctrl+Z дерева работает при фокусе на canvas. Расчёты по-прежнему показывают прочерки, а не выдуманные числа.

Для ошибки пришли действия, текст исключения/первую ошибку сборки, скриншот, разрешение и масштаб Windows. Файлы игры и личный профиль не нужны.

## 0.8.0 — проверка на Windows (F5)

1. Заголовок окна: `0.9.1 · Jewels, Uniques & Honest Resists`. **Если видно 0.6.0 или «Конфигурацию» в меню — запущена старая сборка: распакуй zip в ОТДЕЛЬНУЮ папку и открой .sln из неё.** Слева навигация БЕЗ «Конфигурации» (7 пунктов: Билды, Дерево, Предметы, Умения, Персонаж, Заметки, Настройки).
2. «Билды»: кнопки «Новый билд», «Импорт билда», «Открыть .build / JSON»; на карточке — «Открыть», «Правка билда», «Экспорт .build», дубликат, удалить.
3. Радио «Стартер/Эндгейм» (кнопка «Изменить» на карточке): переключаются строго по одному; на «Эндгейм» страница «Персонаж» показывает Огонь/Холод/Молния −40%.
4. Импорт PoB-кода: «Импорт билда» → вкладка «Код PoB» → вставить код из PoB → «Импортировать» → отчёт (сколько найдено/не распознано) → билд создан, страница «Дерево».
5. Импорт JSON: вкладка «JSON / ссылка» — вставить текст из poe.ninja ИЛИ ссылку → скачивание один раз по кнопке. Файл `.build` — кнопкой «Открыть .build / JSON».
6. Экспорт: «Экспорт .build» на карточке → выбрать путь (можно `Documents\My Games\Path of Exile 2\BuildPlanner`) → файл открывается игрой (проверь в игре: планировщик билдов).
7. «Умения»: быстрое добавление — поиск/выбор умения + уровень + качество → «Добавить»; карточка называется по умению; наведи мышь на значок — игровое описание, увод мыши прячет.
8. «Персонаж»: слева умения, стрелочка раскрывает цифры (удар, удары/с, крит, мана, разбивка по 5 типам, поддержки значками); справа ресурсы/защита/атрибуты, широкая таблица сопротивлений с капом 75%; страница не редактируется.
9. Сеть: при импорте по ссылке — один запрос; офлайн-режим (код/JSON/файл) сети не трогает.
