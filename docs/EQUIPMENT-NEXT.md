## Принятый UX

Не таблица предметов, а визуальная раскладка экипировки в духе игрового инвентаря, с собственным оформлением PoeBuilder:

- Шлем, нательный доспех, перчатки, обувь, пояс.
- Амулет и два кольца.
- Основная и вторая рука; поддерживаемые оружейные наборы.
- Остальные игровые слоты — по проверенному каталогу текущей версии.
- Нажатие на слот открывает редактор предмета, совместимого с этим слотом.

Для нательного доспеха: выбор базы → доступные модификаторы/значения → качество → гнёзда и разрешённые руны/идолы → сохранить/надеть. Не показывать модификаторы, комбинации или пределы из выдуманного каталога.

## Доменная модель

Версионированные базовые предметы, требования, категории, слоты, защитные/оружейные параметры; группы модов, диапазоны и уровни; качество и встроенные модификаторы; содержимое гнёзд и совместимость вставок. Сохранять канонические ID и значения отдельно от отображаемого RU/EN-текста.

Проверять взаимное исключение модов, совместимость типа базы со слотом/модами/вставками, занятость обеих рук, зависимые слоты, требования персонажа. Точные правила и лимиты берутся из проверенных данных, не из приблизительных воспоминаний.

Сначала рабочее создание/редактирование/экипировка/сохранение. Затем парсер текста предмета и интеграция модификаторов с расчётным движком. Не выдавать условные расчёты за результат игры.

## Умения

Каталог активных умений и поддержек, уровни/качество, совместимость, группы и конфигурация. Выбор предмета, умения и изменение дерева должны пересчитывать единый билд только после появления проверенного движка.

## Общий незакрытый источник данных

Полный проверенный каталог предметов/модов/умений и официальные RU-строки ещё не подключены. Требуются источник, версия, условия использования и стабильные ID. Встроенная загрузка установленных файлов игры, неофициальные API GGG и зависимость от исходников PoB не являются планом реализации.
