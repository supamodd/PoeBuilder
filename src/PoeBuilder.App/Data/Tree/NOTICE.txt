Upstream README:
# poe2-skilltree-export
Exported data for Path of Exile 2's Passive Skill Tree.
Please see the OAuth Documentation (https://www.pathofexile.com/developer/docs) for more information.

skills.png is a lossless PNG decoding of upstream assets/skills.webp for WPF.
No icon edits. data.json and skills.json are unmodified upstream files.

notable-effects.json is a PoeBuilder-maintained overlay, generated by build/extract-notable-effects.ps1:
it names the effect art the game also shows under notable/keystone nodes, which the upstream export
lists only for the masteries. Node -> art-name mapping taken verbatim from the pinned reference tree
(TreeData/0_5/tree.json, activeEffectImage), art files are GGG textures shipped in Art/effect/.

Portraits/*.jpg: 31 class/ascendancy frames from the eight official background-<class> atlases at the same commit. Cropped using official coordinates, resized to 640x640, composited on #0D1319, JPEG quality 92. No generated portraits. Source hashes and frame keys: manifest.json.

Art/class/*.png: class and ascendancy backdrops cut out of PoB2's BC7 atlases
(ascendancy-background_1500_1500, ascendancy-background_4000_4000; sprite -> slice mapping
verbatim from its ddsCoords table in TreeData/0_5/tree.lua). Full 1500x1500 slices for the
class/ascendancy art; the 4000x4000 ring art halved to 2000, the size PoB2 draws it at.
Decoded offline by build/tree-art-decoder (C# BC7 decoder, modes 0-7; the BPTC partition and
quantization tables and the bit layout follow the open-source texture decoder
https://github.com/K0lb3/texture2ddecoder, MIT license, Copyright (c) 2020 K0lb3) and the
zstandard frames are inflated with ZstdSharp.Port (MIT, https://github.com/oleg-st/ZstdSharp).
No art edits beyond the 2:1 downscale of the ring art.
